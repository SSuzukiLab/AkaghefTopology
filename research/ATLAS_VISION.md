## 0. 一文

> このWebは、結び目や3次元多様体の標本棚ではなく、Hopf代数から生まれる不変量が
> 位相空間の何を観測しているのかを探索する数学的な観測所である。

Knot Atlas / KnotInfo の中核機能は **辞書性**: 各対象頁に不変量値 (Jones 等) が
必ず載り、「この対象の、この不変量の値はこれ」を引ける。これは本 atlas でも一級の役割。

軸は反転でなく直交する二つ (対立しない):

- **辞書軸 (per-object)**: 対象頁に既知の不変量値を並べる。Knot Atlas の Jones 列と同じ。
  引けることが価値。例: L(2,1) 頁に Z(M;F_p[x]/(x^p)), Z(M,v;R[x])=−1/2 …
- **観測所軸 (per-invariant)**: 一つの不変量構成が対象世界の何を見るかを辿る。
- 最終形: Area 2 / 2.5 / 3 を横断して不変量構成そのものを比較する。

二軸は同じ一枚の表を **行で読むか列で読むか** の違い。分ける必要はない。
真似たいのは「豊富な具体例」「相互参照」「計算可能性」、そして各対象頁に値が必ず載る辞書性。

## 1. 不変量は列ではなく観測装置

MST不変量は値ではなく、構成全体が数学的対象:

    (対象, 図式, 代数, 特殊元, 局所変形) ⟼ 不変量

DC書類の Area 分類表がこの共通言語を与える:

| Area   | 対象              | 図式              | 代数            | 特殊元        | 不変量           | 局所変形          |
|--------|-------------------|-------------------|-----------------|---------------|------------------|-------------------|
| 2      | 結び目・絡み目 L  | 結び目図式        | Drinfeld double | R行列         | RT不変量         | Reidemeister move |
| 2.5    | 多様体内の絡み目 (M,L) | lo-graph (Heegaard-Link図の混合) | ↕混合物 | "C演算子"     | 拡張Kuperberg不変量 | Handle slide/Turaev move |
| 3      | 閉3次元多様体 M   | normal o-graph    | Heisenberg double | "W演算子", S-tensor | Kuperberg / MST不変量 | PS, MP, CP move |

("―" は申請者独自の呼称)

## 2. 主役は「対象の一覧」でなく「不変量の宇宙」

AGTCポスターの2例がこの方向を示す:

- Z(M; F_p[x]/(x^p)) = 0 (|H_1(M)|=∞ または p∤|H_1(M)|), それ以外 1
  — H_1(M) の位数が無限か p で割れるかを検出
- Z(M,v; R[x]) = ±1/|H_1(M)|  (|H_1(M)|<∞, ± は combing v に依存)
  — 同じホモロジー情報を Weyl代数・形式トレース・正則化で読み取る

面白さは「L(2,1) の値が −1/2」ではなく:

> 異なるHopf代数を通して多様体を見ると、同じ位相情報が異なる姿で現れる。
> では量子群を通すと何が見えるか。非対合的代数で枠はどう現れるか。

この問いがサイトの中心。

## 3. 見たいサイト像

- **WA1 研究領域の地図が最初にある**
  図のカタログでなく、Area表を育てた数学地図。"MST invariant" を開くと
  入力/図式/代数/特殊元/必要なmove不変性/既知定理/未解明境界 が一望できる。

- **WA2 「この不変量は何を見ているか」を辿れる**
  値の表だけでなく、証明済みで捉える情報 / 計算から予想される情報 /
  区別できなかった対象 / 他不変量との関係 / 有限↔無限次元での差 を並べる。
  R[x] なら H_1(M) → Weyl代数計算 → 行列式公式 → Alexander多項式とのアナロジーへ辿れる。

- **WA3 対象頁は試験片として存在する**
  L(2,1), S^3, Poincaré球面 は主役でなく、不変量を照らし合わせる試験片。
  一つの多様体を各代数がどう見るかを横比較。KnotInfoの表に近いが各セルに計算過程と理論的由来がある。

- **WA4 証明と計算実験が同じ地平に並ぶ (ただし混同しない)**
  evidence-class を明示: 定理(証明済) / 計算で多数確認 / 予想 / 未定義・未解明 / 反例探索中。
  VISUAL_VERIFICATION.md の「evidence ≠ final acceptance」思想と同型。

これは DC の研究サイクル「発想 → 実装 → 計算 → 理論化」を外から見える形にする。

## 4. 中核データ — 辞書と観測所を同時に作る

中核は一つの **値レコード (表のセル)**:

    (対象, 図式, 代数, 特殊元) ⟼ 値 + evidence-class + 計算過程へのlink

- 対象頁 = 値レコードを対象ごとに横へ集める (辞書軸 / Knot Atlas型)
- 不変量頁 = 値レコードを不変量構成ごとに縦へ集める (観測所軸)
- 同じcanonを二つの向きから読むprojectionであり、値を二重管理しない。

対象頁に最低限載せたい辞書項目:

- 対象名と表示 (o-graph / o-data)
- 対象に付随する既知の基礎量 (例: H_1(M))
- 適用可能な各不変量の値
- 値の条件 (combing / framing / weight / Hopf代数 / パラメータ)
- evidence-class (定理 / 検証計算 / 予想 / 未計算)
- 再計算するJuliaコードまたは計算記録へのlink

## 5. 古い数学辞書を生まれ変わらせる

本構想は新しい o-graph atlas を一から作ることだけではない。既に価値あるデータを持つが、
専門家の暗黙知を前提として読みにくくなった数学辞書を、意味を失わず現代に蘇らせる。

先行例: Kouno の [DS-diagram 0–6](https://math.cs.kitami-it.ac.jp/~kouno/DS-diagram/DS-diagram0-6.html)。
既に DS diagram の辞書として、名前 / DS名 / 多様体 / generator / reducible / Matveev / data を持つ。
しかし `Σ(5,1)`, `R[1:1]`, `#1^2_2`, `* 1 2 -3 ...` の文法・意味・列間の関係は、
専門家の暗黙知を前提にし、現在の利用者には辿りにくい。Akaghef自身も一部記号の意味を
確信できない。したがって単なるHTMLの美装でなく、暗黙知を回収する数学研究を含む。

### DS と o-graph の境界

- DS diagram と o-graph は扱う対象・表示理論が異なる。データモデルを混ぜない。
- 各辞書は対象固有の名前・同値関係・記号・計算法を独立に尊重する。
- 共有するのはデータそのものではなく、**数学辞書としての読解体験**:
  原記号 / 平易な読み / 図 / 定義 / 典拠 / 関係 / 計算・検証可能性。

### 「生まれ変わる」の意味

- **保存**: 原サイトの値・名称・典拠を失わず、原表記も必ず残す。
- **翻訳**: 各記号をクリックすると、読み方・定義・そのセルでの意味へ辿れる。
- **可視化**: 生データを図式として描き、記号列と図上要素を対応させる。
- **文脈化**: 「この多様体のどの表示か」「別名・他辞書との対応は何か」を示す。
- **検証**: 可能な項目には、値を再計算するコード・条件・evidenceを結ぶ。
- **未解明の可視化**: 意味を確認できない記号を推測で埋めず、unknownとして専門家への問いにする。

目標は、専門家にしか読めない表を初心者向けに薄めることではない。

> 原典の情報密度を保ったまま、どの読者も意味へ降りていける層を作る。

これは「数学を機械可読化する」と同時に、「数学者の暗黙知を人間可読のまま継承する」仕事である。

## 6. 実装への含意 (canon → projection)

- julia/ = canon (計算・構成の実体)。サイトは projection。canon を二重化しない。
- 同定問題 (2図式が同一多様体か) は一般に困難。IDは「多様体クラス」に直接振らず、
  正規形など計算で閉じる representation に振り、クラスは typed-edge (evidence属性付き) で束ねる。
- 玄関 (現状の3図ページ) は当面維持。最初の本格展示は図の追加でなく、AGTCポスターを題材にした
  一つの数学的物語「F_p[x]/(x^p) と R[x] は3次元多様体の何を見るか」。

## 7. framing の位置づけ (重要・理由は未回収)

framing (枠) を扱えることは、**不変量研究の文脈で決定的に重要** (Akaghef 断定)。
o-graph の理論的優位性の核心はここにある。

ただし *なぜ決定的か* の具体的機序は、最新研究の文脈を Akaghef から共有された後に記述する。
現時点で理由を推測で埋めない (DS サイトが陥った「暗黙知の凍結」の再生産を避ける)。

分かっている枠組みだけ (一般論、未検証):

- WRT 不変量は枠情報を捨てる位相不変量。Kuperberg / MST 不変量は同じ入力で枠を保持しうる。
- ℤ_2-weighted / ℤ-weighted o-graph が枠付き 3 多様体を組合せ的に扱う ([BP97][MST22])。
- 非対合的 Hopf 代数 (量子群) の不変量には枠と balancing element の扱いが要る (AGTC ポスター Future Directions)。
